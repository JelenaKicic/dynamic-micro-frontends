# announcements-react

Micro-frontend showing faculty announcements (огласна плоча), loaded from the
faculty's public API.

**Stack:** React, Redux Toolkit Query for data fetching, and MUI for the UI.
Packaged as a `micro-announcements-react` web component.

## Run

```sh
pnpm install
pnpm start     # dev server
pnpm build     # production build
```
