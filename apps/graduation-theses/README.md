# Graduation Theses

Micro-frontend that displays graduation theses and their statuses for the first
cycle of studies at the Faculty of Electrical Engineering in Banja Luka.

**Stack:** React, Redux Toolkit Query for data fetching, and MUI for the UI.

## Run

```sh
pnpm install
pnpm start     # dev server at http://localhost:3000
pnpm build     # production build
```
